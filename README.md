# Substance Zero

Substance Zero is a 2D top-down sci-fi roguelike action RPG built in Godot. Players fight through procedurally generated combat rooms, purchase power-ups, and pilot a spaceship through zero-gravity space segments between planets.

## Play
- Web build (itch.io): https://tyger8540.itch.io/substance-zero

## My Contribution (Movement, Physics, Game Feel)
**Role:** Gameplay Programmer (Movement, Physics, Camera)
- Implemented **player movement and dash mechanics** using a command-based architecture, including timing-locked dash behavior and consistent diagonal movement.
- Designed and built **zero-gravity spaceship movement**, including acceleration-based controls, rotational steering, and controlled deceleration for playability.
- Developed **camera systems** for both ground and space gameplay, iterating between autoscroll and player-follow designs to improve game feel.
- Tuned gameplay parameters (speed, acceleration, dash timing, input layout) to improve responsiveness, consistency, and overall game feel.
- Contributed to **space level implementation**, including large-scale asteroid generation and time-based exploration mechanics.
